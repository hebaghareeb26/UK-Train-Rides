- Tasks: Determine Data Analysis Questions: Determine all possible analysis questions that can be deducted from the given dataset and would be of interest to the organization's decision makers. Predict number of rides for the next month. Then, accordingly, highlighting the forecasted revenue during each day of the next month. Also, you need to specify the demand on different ticket classes.

### Week 3: Dashboard Phase

- Deliverables: Power BI dashboard.

### Week 4: Final Presentation

## KPIs

### Revenue & Sales
| KPI | Description |
|-----|-------------|
| **Total Revenue** | Total income generated from all ticket sales |
| **Total Tickets** | Total number of tickets sold |
| **Average Ticket Price** | Average revenue per ticket |
| **Online Revenue %** | Share of revenue coming from online purchases |
| **Online Revenue / Station Revenue** | Revenue split by purchase channel for each ticket class |
| **Revenue with / without Railcard** | Revenue comparison between railcard and non-railcard tickets |

### Customer Behavior & Booking Patterns
| KPI | Description |
|-----|-------------|
| **Busiest Weekday** | Weekday with the highest number of tickets |
| **Busiest Month** | Month with the highest number of tickets |
| **Same Day Booking %** | Share of tickets booked on the day of travel |
| **Advance Tickets %** | Share of tickets booked in advance |
| **Off-Peak Tickets %** | Share of tickets purchased for off-peak travel |
| **Avg Advance Days (Long Journeys)** | Average days between booking and travel for long journeys |

### Routes & Demand
| KPI | Description |
|-----|-------------|
| **Top Route Revenue** | Revenue of the highest-earning route |
| **Peak Hours Share %** | Share of tickets for peak-hour departures |
| **Advance Tickets Share %** | Share of advance tickets across routes |
| **Average Days Before Travel** | Average booking lead time before the journey |
| **Tickets by Weekday** | Ticket demand distribution across weekdays |

### Operational Performance & Delays
| KPI | Description |
|-----|-------------|
| **On-Time Rate %** | Percentage of journeys that ran on time |
| **Delay Rate %** | Percentage of journeys that were delayed |
| **Cancelled Rate %** | Percentage of journeys that were cancelled |
| **Delayed Trips** | Total number of delayed journeys |
| **Avg Delay Minutes** | Average delay duration in minutes |
| **Top Delay Reason** | Most frequent cause of delays |

### Refunds & Financial Impact
| KPI | Description |
|-----|-------------|
| **Net Revenue** | Revenue after deducting refunds |
| **Total Refund Requests** | Number of refund requests submitted |
| **Average Refund Value** | Average amount refunded per request |
| **Refunded Trips %** | Percentage of trips that ended with a refund |
| **Total Refund Financial Loss** | Total revenue lost due to refunds |
| **Disrupted Trips Count** | Number of trips affected by delays or cancellations |
| **Refund Rate %** | Refund rate by journey status and by delay reason |
